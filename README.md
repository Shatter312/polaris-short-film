# PØLÆRIS — short film

Extract the archive and open index.html in Chrome, Edge, Firefox or Safari. Scroll normally, or use Page Down and the arrow keys to scrub. Home returns to the opening. All assets are included. No server, build step, dependencies, or internet connection is required.

The sequence and camera are in film.js. The opening, blackout, lone pinpoint, surrounding stars, monitor, tracker, breach, and final emblem occupy successive portions of the native scroll range. The page honors the system reduced-motion preference with discrete still frames.

## Assets

- assets/mokka-tree.jpg — Mokka-tree.jpg from the Garuda Linux wallpapers repository at https://gitlab.com/garuda-linux/themes-and-settings/artwork/garuda-wallpapers/-/blob/master/src/garuda-wallpapers/Mokka-tree.jpg. The file is unmodified. The film grades it to monochrome at runtime. The upstream repository license is included in assets/Garuda-LICENSE.txt.
- assets/monitor.png — Original plate generated with built-in ImageGen. Prompt brief: a straight-on photoreal 35mm film still of a blank black monitor and keyboard on a charcoal desk, with faint ultramarine bias lighting, grayscale surroundings, and no branding.
- assets/compass.png — Supplied PØLÆRIS emblem.

## Hosting

Import the GitHub repository in Vercel as an Other project, serving the repository root without a build command. No environment variables are required.
